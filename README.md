# Criaturas del Claro

Una aventura Android original de exploración, criaturas coleccionables y combates por turnos. Incluye un mapa de tiles dibujado en tiempo real, sprites originales, diálogos, una misión principal y encuentros aleatorios. No utiliza personajes, marcas ni recursos de Pokémon.

## Ejecutar

1. Abra este directorio en Android Studio.
2. Instale un Android SDK con la plataforma API 35.
3. Ejecute la configuración `app` en un emulador o dispositivo Android (API 24 o superior).

## Cómo jugar

- Cierre el cuadro introductorio y use los cuatro botones del mando, o deslice el dedo, para moverse por la Pradera Lúmina.
- El césped alto produce encuentros aleatorios. Durante un encuentro, elija entre dos movimientos, lance una esfera o huya.
- Hable con Lina en el sendero y busque la Flor de Estrella al norte para completar la historia.
- Las criaturas, personajes y escenarios son sprites originales trazados mediante `Canvas`, sin recursos de terceros.
